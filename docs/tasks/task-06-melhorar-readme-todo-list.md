# Task 6 — Melhorar o README do projeto Todo List

## Status da validação

**Task original:** "Melhorar o readme do projeto Todo List"

**Resultado:** ⚠️ Mesma limitação da [task 5](task-05-melhorar-readme-todo-list.md) — a task em si continua genérica (não diz *o que* está faltando no README atual nem define stack/escopo/licença). Como o repositório ainda não tem código-fonte, essas informações não podem ser inferidas.

### O que já estava resolvido (herdado da task 5)

- README na raiz, em pt-BR, com todas as seções padrão (sobre, status, funcionalidades planejadas, tecnologias, pré-requisitos, instalação, uso, estrutura, como contribuir, licença).
- Pendências reais (stack, plataforma, escopo, licença) sinalizadas como "a definir", sem inventar conteúdo.

### Campos que ainda faltam para o desenvolvimento (inalterados)

- Stack técnica, plataforma-alvo, escopo funcional detalhado e licença — dependem de decisão do responsável pelo projeto, não de quem escreve o README.

## Task melhorada

**Título:** Tornar as decisões pendentes do README acionáveis

**Descrição:** Já que o conteúdo do README está completo dentro do que é possível saber hoje, a melhoria possível nesta rodada é de **processo**: deixar claro como e onde cada decisão pendente (stack, plataforma, escopo, licença) deve ser registrada, para que a próxima pessoa que tiver essa informação saiba exatamente o que fazer.

**Critérios de aceite:**
- [x] Lista de decisões pendentes em formato de checklist (`- [ ]`), não apenas prosa.
- [x] Instrução explícita de onde registrar cada decisão (`docs/tasks/`, referenciado em PR).

## Entregável desta etapa

`README.md` com a seção "Status do projeto" convertida em checklist e uma frase explicando o fluxo de registro de decisões futuras. Nenhum conteúdo técnico foi inventado — a task segue bloqueada nos mesmos 4 pontos já identificados na task 5, e continuará bloqueada até que alguém com autoridade sobre o projeto forneça essas respostas.
